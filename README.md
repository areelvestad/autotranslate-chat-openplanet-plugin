# Autotranslate Chat

Translates ManiaPlanet server chat with LibreTranslate. Made to help non-French speakers follow chat on ShootMania servers.

Tested on ShootMania servers with a self-hosted LibreTranslate server.

## Setup

1. Put the plugin folder in `%USERPROFILE%\Openplanet4\Plugins\`.
2. Start ManiaPlanet and press **F3**.
3. Load **Autotranslate Chat** from the **Plugins** menu.
4. Open Openplanet **Settings** and select **Autotranslate Chat**.
5. Enter your LibreTranslate server address. Use `/translate` as the endpoint.
6. Set the source language to `auto` and choose a target language.
7. Enter an API key if your server requires one.
8. Open the in-game chat history to let the plugin read messages.

Use **Collapse chat** to hide the translated messages. Click **Show translated chat** to bring them back.

LibreTranslate: https://libretranslate.com/
